# Редактор послідовності сцен

Відкрий **ReflectionOfAmber → Narrative Graph** у Unity.

1. Перетягни `Narrative_early_game`, `Narrative_mid_game`, `Narrative_end_game` або `Narrative_all` із `Assets/ReflectionOfAmber/Configs/Graphs` у поле **Layout**. Кнопка **All scenes** відкриває всі сцени з цієї папки.
2. Перетягни вихід потрібного варіанта на **Input** іншої сцени. Змінюється лише ціль: текст вибору, умови й порядок варіантів зберігаються.
3. **+ Add option** додає варіант; **−** видаляє весь варіант. Видалення самого ребра лише очищає ціль. Порожні виходи залишаються видимими.
4. **Inspector: text / conditions** відкриває asset сцени для редагування текстів та умов. **Inspect** біля special-переходу відкриває спільний special asset. Зміни Inspector підхоплюються графом; **Refresh links** оновлює зв'язки вручну.
5. **Save** зберігає розкладку та змінені сцени/спеціальні переходи з Configs/Graphs. **Save as…** створює іншу розкладку. Розкладки використовують ті самі сцени, тому зміна переходу відображається в усіх розкладках.

Пошук і **Find** знаходять сцену у відкритій розкладці. **Frame all** показує весь граф. Правою кнопкою можна додати сцену, return-посилання чи групу. Вузол із **↩** є другим відображенням того самого asset; **Expand scene here** розгортає його виходи тут. Видалення вузла з полотна не видаляє asset і не переписує переходи. Ціль за межами розкладки може знову з'явитися як вузол-посилання після оновлення.

**START** — лише маркер розкладки, він не змінює стартову сцену гри. Undo/Redo працює для переходів і змін розкладки. Scene assets змінюються відразу в пам'яті Unity; відмова від збереження розкладки не скасовує ці зміни — для цього використовуй Undo.

## Перевірка

Кнопка **Validate** або **ReflectionOfAmber → Validate scenes** перевіряє всі сцени у Configs/Graphs. Результати дозволяють вибрати asset чи знайти сцену на графі.

- Пряме посилання сцени на себе — помилка; створення такого ребра через граф заборонене, зокрема через її return-вузол.
- Повернення через інші сцени дозволені.
- Варіант із порожньою ціллю — помилка. Сцена без варіантів — коректне завершення.
- Увімкнені special-переходи перевіряються за їхніми серіалізованими альтернативами без запуску ігрової логіки. Titre-анімація не має переходу й не потребує цілі.
- Перевірка нічого не виправляє автоматично і не блокує збереження інших змін.

Регресійні перевірки: **ReflectionOfAmber → Tests → Scene graph checks**. Вони використовують тимчасові об'єкти й тестовий asset, який прибирають після завершення. Наявні сюжетні assets лише читаються.
