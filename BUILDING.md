# Збірка Demo та Full

У Unity доступні команди `Build > Build Demo` та `Build > Build Full`.

## Як зібрати гру

1. Дочекайтеся імпорту скриптів у Unity та вийдіть із Play Mode.
2. У `File > Build Profiles` виберіть свій профіль для Windows, macOS або Linux та натисніть `Switch Profile`, щоб зробити його активним. Дочекайтеся імпорту/компіляції. Самого виділення профілю у списку недостатньо. Стандартні профілі платформ також підтримуються.
3. Перевірте список увімкнених сцен і параметри активного профілю. Якщо ввімкнено Override Global Scene List, використовуються сцени профілю; інакше — глобальний список. Development Build, Script Debugging та інші параметри збірки читає Unity із профілю.
4. Якщо потрібна нова локалізація, виконайте `Update Localization` у контекстному меню LocalizationConfig, дочекайтеся повідомлень про успіх обох завантажень і збережіть asset. Нові команди збирають уже збережену локалізацію та пропускають старе асинхронне оновлення в PreBuildManager.
5. Виберіть `Build > Build Demo` або `Build > Build Full`. Збережіть сцени, якщо Unity запропонує. Після перекомпіляції процес продовжиться автоматично.
6. Після успішної збірки відкриється папка результату. У разі помилки дивіться Console: збірка Player не починається, якщо Addressables завершилися помилкою.

## Що перемикається

| Налаштування | Demo | Full |
| --- | --- | --- |
| `GAME_DEMO` | Додається | Видаляється |
| `MainStory / Include in Build` | Вимкнено під час збірки | Увімкнено під час збірки |
| `Prologue`, `Default Local Group` | Увімкнено під час збірки | Увімкнено під час збірки |
| Папка результату | `Builds/Demo/<платформа>/` | `Builds/Full/<платформа>/` |

Для власного профілю до папки результату додається `<назва-профілю>-<8-символів-GUID>/`, щоб різні профілі не перезаписували збірки один одного.

Для власного профілю `GAME_DEMO` додається/видаляється в його Scripting Defines. Цей символ також прибирається з ефективних Player Settings, якщо був там, оскільки defines профілю додаються до них і не можуть скасувати глобальний символ. Якщо профіль успадковує глобальні Player Settings, це прибирає GAME_DEMO саме з глобальних налаштувань. Інші символи не змінюються. Для стандартного профілю платформи GAME_DEMO перемикається безпосередньо в Player Settings, як раніше.

`GAME_FINAL` та інші scripting defines зберігаються. Якщо потрібна релізна поведінка існуючих скриптів (зокрема видалення об'єктів FinalExclude та вибір релізних ключів аналітики), заздалегідь додайте `GAME_FINAL` у Scripting Defines свого профілю або його Player Settings. Full означає повний контент, а не автоматичне ввімкнення `GAME_FINAL`.

Власний профіль збирається через `BuildPlayerWithProfileOptions`; його параметри не замінюються фіксованими налаштуваннями команди. Для стандартного профілю платформи зберігається `BuildOptions.None`. Назва виконуваного файла — ReflectionOfAmberDemo або ReflectionOfAmber із розширенням платформи.

Наприклад, активуйте свій профіль Windows Demo та натисніть `Build > Build Demo`. Для повної версії активуйте Windows Full і натисніть `Build > Build Full`. Назви профілів довільні: варіант визначає команда, а не назва. Звичайна кнопка Build у вікні Build Profiles не запускає цю автоматизацію Addressables; використовуйте команди меню Build.

## Після збірки

- Вибраний `GAME_DEMO` залишається активним/неактивним відповідно до останньої команди. Це також впливає на наступний Play Mode.
- Власний профіль залишається активним, а зміна його defines зберігається в asset. Якщо під час очікування змінити активний профіль чи платформу, запит збірки скасовується.
- Початкові прапорці включення груп, Addressables build script та налаштування автоматичної збірки Addressables відновлюються навіть після помилки.
- Згенерований контент Addressables відповідає останній збірці. Для іншого варіанта знову запускайте відповідну команду — не копіюйте старий контент вручну.
- Повторна збірка того самого варіанта використовує ту саму папку. Для архіву скопіюйте попередній результат перед запуском.
- `Build > Cancel Pending Build` скасовує очікування перекомпіляції, але не зупиняє вже запущену збірку та не повертає defines. Очікування не зберігається після закриття Unity.
- Активний Addressables Profile зберігається. Якщо використовуєте віддалений контент, його завантаження на сервер і окремі адреси для Demo/Full потрібно налаштувати додатково.

## Перевірка змін

Editor-скрипти перевірені компілятором із Unity 6000.0.45f1 та локальними збірками проєкту, окремо з GAME_DEMO і без нього. Повні збірки Player та перевірка їх запуску потребують виконання в Unity.
